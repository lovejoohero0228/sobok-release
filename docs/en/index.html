Get started

1Ask your AI

  1. Open an AI that works directly on your computer. For example the Codex app, Claude Code, Cowork in the Claude desktop app, or Cursor.
  2. Press Copy below, paste it to your AI, and send.
  3. If the AI asks whether it can run a command, allow it. Sobok starts by itself when the install finishes.

2Open it

Next time, search for Sobok in the Start menu (Windows) or Spotlight (Mac) and click it.

1Install

  1. Press Copy below.
  2. Press the Windows key + R together.
  3. In the Run box that appears, paste with Ctrl + V and press Enter.
  4. Sobok starts by itself when the install finishes.
powershell -c "irm https://raw.githubusercontent.com/lovejoohero0228/sobok-release/main/install.ps1 | iex"

2Open it

Search for Sobok in the Start menu and click it.

1Install

  1. Press Copy below.
  2. In Finder, double-click Applications → Utilities → Terminal. If you use Spotlight (⌘ + Space) instead, click the black Terminal app itself rather than pressing Enter.
  3. Paste with ⌘ + V and press Enter.
  4. Sobok starts by itself when the install finishes. If a window asks for Accessibility access, turn Sobok on. That lets snow pile up on the Dock too.
curl -fsSL https://raw.githubusercontent.com/lovejoohero0228/sobok-release/main/install-mac.sh | bash

Settings

There is a tiny snowman hiding on your screen. Click it to open Settings.

Change how much it snows, how the snowmen talk to you,
how often they talk, the text size, and the language.

If your computer slows down, turn on Light mode.

Uninstall

Show how to uninstall

Sad to see you go. This removes Sobok completely.

Press the Windows key + R, paste the line below, and press Enter.

powershell -c "irm https://raw.githubusercontent.com/lovejoohero0228/sobok-release/main/uninstall.ps1 | iex"

Paste the line below into Terminal and press Enter.

curl -fsSL https://raw.githubusercontent.com/lovejoohero0228/sobok-release/main/uninstall-mac.sh | bash
