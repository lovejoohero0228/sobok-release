시작하기

1AI에게 시키기

  1. 내 컴퓨터에서 직접 일하는 AI를 열어요. Codex 앱, Claude Code, Claude 데스크톱 앱의 Cowork, Cursor 같은 것들이에요.
  2. 아래 복사하기를 눌러 AI에게 붙여 넣고 보내요.
  3. AI가 명령을 실행해도 되는지 물으면 허용해 주세요. 설치가 끝나면 소복소복이 저절로 켜져요.
소복소복을 내 컴퓨터에 설치해 줘. 눈 내리는 바탕화면 위젯이야. ■ 네가 이 컴퓨터에서 명령을 직접 실행할 수 있다면 1. 운영체제를 네가 직접 확인해. 나에게 묻지 마. 2. 맞는 명령을 그대로 실행해. Windows: powershell -c "irm https://raw.githubusercontent.com/lovejoohero0228/sobok-release/main/install.ps1 | iex" Mac: curl -fsSL https://raw.githubusercontent.com/lovejoohero0228/sobok-release/main/install-mac.sh | bash 3. sobok 프로세스가 켜졌는지 확인하고 "설치 끝! 화면에 눈이 내리는지 보세요."라고 알려 줘. Mac 이면 "손쉬운 사용 허용 창이 뜨면 소복소복을 켜 주세요."도 덧붙여. - 명령은 한 글자도 바꾸지 마. 관리자 권한(sudo)을 쓰거나 다른 프로그램을 설치하지 마. - 나에게 명령을 입력하라고 시키지 마. 오류가 나면 원인을 확인하고 한 번 더 해 봐. ■ 명령을 직접 실행할 수 없다면 (웹이나 휴대폰 대화창) 설치한 척하지 마. 아래 순서대로만 해. 1. 아래 글을 그대로 보여 주고 답을 기다려. 선택지는 꼭 같이, 한 줄에 하나씩 보여 줘. 누를 수 있는 선택 버튼을 띄우는 기능이 있으면 그것으로 띄워. 여기서는 컴퓨터에 직접 설치할 수 없어요. 혹시 Codex 앱, Claude Code, Claude 데스크톱 앱의 Cowork, Cursor 처럼 내 컴퓨터에서 직접 일하는 AI 를 이미 쓰고 계신가요? 1) 네, 쓰고 있어요 2) 아니요, 잘 모르겠어요 (번호만 보내도 돼요) 2. 쓰고 있다고 하면 아래 글을 그대로 보여 주고 끝내. 좋아요! 그럼 이렇게 해 주세요. 1) 평소 쓰시는 그 앱을 열고 새 대화를 시작해요. 2) 방금 저에게 보내신 첫 메시지를 처음부터 끝까지 그대로 복사해서 붙여 넣고 보내요. "소복소복을 내 컴퓨터에 설치해 줘"로 시작하는 글이에요. 3) 명령을 실행해도 되는지 물으면 허용해 주세요. 그 AI가 설치까지 해 드려요. 3. 안 쓴다거나 모르겠다고 하면 새 앱을 권하지 말고, 직접 설치하는 방법을 안내해. 먼저 "1) Windows 2) Mac" 선택지로 어느 쪽인지 묻고, 한 번에 한 단계씩 말해. 내가 "했어"라고 하면 다음 단계로 가. Windows 1) Windows 키와 R 을 같이 눌러요. 작은 "실행" 창이 떠요. 2) 위의 Windows 명령을 복사해서 그 창에 붙여 넣고 Enter 를 눌러요. 3) 파란 창이 잠깐 떴다 닫히고 눈이 내리기 시작하면 끝이에요. Mac 1) Finder 를 열고 응용 프로그램 → 유틸리티 → 터미널을 더블클릭해요. (검색창으로 찾을 때는 Enter 대신 검은 창 모양의 "터미널" 앱을 직접 클릭해요.) 2) 위의 Mac 명령을 복사해서 열린 창에 붙여 넣고 Enter 를 눌러요. 3) 눈이 내리기 시작하면 끝이에요. "손쉬운 사용" 허용 창이 뜨면 소복소복을 켜 주세요. 명령을 안내할 때는 복사하기 쉽게 코드 상자에 한 줄로 보여 줘.

✅ 화면에 눈이 내리기 시작하면 성공이에요.

이런 AI를 써 본 적이 없다면 위의 Windows / Mac 탭이 더 빨라요. 평소 쓰는 ChatGPT 나 Claude 대화창에 붙여 넣어도 같은 방법을 한 단계씩 알려 줘요.

2실행하기

다음부터는 시작 메뉴(Windows)나 화면 위쪽 돋보기(Mac)에서 소복소복을 검색해서 클릭해요.

1설치하기

  1. 아래 복사하기를 눌러요.
  2. Windows 키 + R 을 같이 눌러요.
  3. 뜬 실행 창에 Ctrl + V 로 붙여 넣고 Enter 를 눌러요.
  4. 설치가 끝나면 소복소복이 저절로 켜져요.
powershell -c "irm https://raw.githubusercontent.com/lovejoohero0228/sobok-release/main/install.ps1 | iex"

2실행하기

시작 메뉴에서 소복소복을 검색해서 클릭해요.

1설치하기

  1. 아래 복사하기를 눌러요.
  2. Finder 에서 응용 프로그램 → 유틸리티 → 터미널을 더블클릭해서 열어요. 검색창(⌘ + Space)으로 찾을 때는 Enter 대신 검은 창 모양의 터미널 앱을 직접 클릭해요.
  3. ⌘ + V 로 붙여 넣고 Enter 를 눌러요.
  4. 설치가 끝나면 소복소복이 저절로 켜져요. 손쉬운 사용 허용 창이 뜨면 소복소복을 켜 주세요. 그래야 Dock 위에도 눈이 쌓여요.
curl -fsSL https://raw.githubusercontent.com/lovejoohero0228/sobok-release/main/install-mac.sh | bash
